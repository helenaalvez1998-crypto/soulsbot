NARABOT V57 — AUDITORIA INTEGRAL DO CATÁLOGO

1. Faça backup da pasta atual do projeto.
2. Extraia este ZIP em uma pasta separada para validar antes de substituir a versão em produção.
3. Compare o arquivo .env atual com env.example; não substitua segredos nem tokens.
4. Preserve o banco colizeu.db atual. Esta versão não executa migração de banco.
5. Substitua os arquivos do projeto pelos desta versão após validar o ambiente.
6. Reinicie o bot/site para carregar o catálogo e os novos textos.
7. A versão de artes foi elevada para 26; as imagens devem ser regeneradas pelo mecanismo de cache quando solicitadas.
