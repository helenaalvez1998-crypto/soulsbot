# Instalação — Narabot V70

1. Faça uma cópia de segurança da instalação atual.
2. Extraia o conteúdo deste pacote mantendo a estrutura de pastas do projeto.
3. Substitua os arquivos da versão anterior pelos arquivos da V70.
4. Reinicie o processo do bot/servidor para carregar os módulos Python atualizados.
5. No navegador, recarregue a página do Ateliê com `Ctrl + F5` para atualizar o JavaScript e os estilos.
6. Gere um prompt de teste no Ateliê. Confira as três saídas: análise artística, prompt profissional e negative prompt.
7. Confirme que os metadados indicam proporção 5:4 e resolução 1200 × 960.

Não há migração de banco de dados prevista para esta atualização.

O projeto entrega instruções textuais para geração de arte; a geração da imagem continua sendo feita no serviço/modelo de imagens conectado pelo operador. As imagens enviadas pelo fluxo de upload são normalizadas para 1200 × 960 px.
