# Coliseu — layout integral das cartas (V17)

- A ilustração passa a ocupar o fundo de toda a carta, sem ser apresentada como um bloco separado.
- Nome, raridade, facção/fileira, exemplar, poder e ações permanecem sobrepostos em painéis legíveis.
- Mantidos os endpoints de imagem, prioridade das artes oficiais do Ateliê e os atributos de cada carta.
- Cartas do construtor e do deck usam altura mínima integral, grid com linhas esticadas e overflow visível no contêiner.
- Ajuste responsivo para telas menores.

A alteração é exclusivamente visual; não altera regras, custos, coleção ou persistência.
