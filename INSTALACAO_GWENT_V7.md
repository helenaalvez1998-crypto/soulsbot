# Instalação — Gwent V7

1. Faça backup do banco de dados e da pasta atual do bot.
2. Desligue o processo do bot.
3. Extraia o pacote sobre a pasta `narabot-main`, substituindo os arquivos.
4. Preserve `.env`, banco de dados, pasta de dados e artes personalizadas.
5. Reinicie o bot.
6. Atualize o site com `Ctrl + F5`.

A V7 não apaga nem recria a coleção. A conversão dos IDs antigos é feita automaticamente ao carregar o catálogo do Gwent.
