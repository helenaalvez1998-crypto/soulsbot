SOULSBOT — SITE INTEGRADO

Este pacote substitui o bot.py atual e adiciona a pasta site/.

O site é servido pelo próprio servidor HTTP do SoulsBot, no mesmo domínio da API.
Isso permite que o login Discord use a mesma sessão/cookie sem configurar CORS.

Arquivos:
- bot.py: versão do bot com frontend servido em /, /style.css e /app.js.
- site/index.html: estrutura da interface.
- site/style.css: aparência responsiva.
- site/app.js: integração com /api/me, /api/collection e imagens das cartas.

IMPORTANTE:
1. Substitua o bot.py do GitHub pelo bot.py deste pacote.
2. Crie uma pasta chamada site na raiz do repositório.
3. Dentro dela, envie index.html, style.css e app.js.
4. Não apague os demais arquivos do projeto.
5. Faça o deploy na FadeHost.

A página de coleção e os dados são reais. Montagem de deck e duelos ainda não estão habilitados nesta etapa.
