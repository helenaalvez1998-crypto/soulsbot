# Instalação — Molduras V10

1. Faça backup da pasta atual do bot.
2. Desligue o bot.
3. Extraia o conteúdo deste ZIP sobre a pasta `narabot-main` existente.
4. Preserve seu `.env`, banco de dados e dados locais (`data/`).
5. Reinicie o bot.

Não é necessário recriar cartas, coleções ou decks. A versão do renderizador foi atualizada para V10 e o cache visual antigo será invalidado automaticamente.

A área da ilustração e o mecanismo atual de envio/substituição de arte não foram alterados.
