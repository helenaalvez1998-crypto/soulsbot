# Prompts dos templates completos das cartas (5 raridades)

Como usar: anexe `guia_template_carta_limpo.png` na IA de imagem e cole **um** dos prompts abaixo. Cada prompt já é completo (layout + estilo da raridade). Gere em retrato **840 × 1240** (ou o mais próximo que a ferramenta permitir; até ~6% de diferença de proporção é aceito). Se aparecer qualquer letra, apague no editor antes de enviar em `/adm` → Jogos, Coliseu e runs → Templates das cartas.

Dicas: peça sempre o mesmo layout nas cinco; se a IA deslocar uma placa, não precisa refazer: o bot detecta a janela da arte sozinho e as demais posições podem ser ajustadas com um arquivo JSON (veja `TEMPLATES_CARTAS_GUIA.md`).


## Comum

```
Using the attached layout guide image as the exact reference for where things go, create the TEMPLATE of a vertical collectible trading card, portrait 840x1240 px, fully opaque (no transparent areas, no rounded-corner cutouts). The template is EMPTY: do NOT draw any text, letters, numbers, logos, watermarks, characters or scenery anywhere.

Layout (follow the guide, same positions on every card):
- Top right: a small empty badge plate for the rarity name.
- Below it: a wide empty name banner plate, room for two lines of text.
- Center: one large horizontal ART WINDOW (about 87% of the card width, ~5:4), filled with FLAT PURE MAGENTA #FF00FF, no gradient, no shadow, no texture, crisp straight edges, with only a thin ornate border around it.
- Lower left: an empty round medallion for a big power number.
- Lower right: two stacked, empty horizontal plates (type and cost).
- Bottom: a wide empty rectangular plate for ability text.
All plate interiors must be calm, dark and low-contrast so white text stays readable. Symmetric, centered, dark-fantasy souls-like mood. Rich detail only on the frame and ornaments.

RARITY STYLE (COMMON): simple worn iron and dark steel frame, matte gunmetal gray with faint silver edge highlights, minimal ornaments, small rivets at the corners, plain beveled plates, subtle scratches and wear. Humble and sturdy, no glow.

Final check: no text anywhere, window is flat magenta #FF00FF, all plates empty, layout identical to the guide.
```
